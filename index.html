📋 Contract Clause Analyzer

AI-Powered Commercial Contract Analysis

Team: Alison Manna, Akshay Arun, Satomi Ito
Course: DSAN 6725 — Applied AI (Spring 2026)

🎯 Project Overview

A multi-agent AI system that automatically analyzes commercial contracts by parsing clauses, classifying them by type, scoring risk factors, and benchmarking against industry standards.

Built with LangGraph for agent orchestration and Claude Haiku for intelligent analysis.

✨ Key Features

  • Clause Classification: Identifies 41 clause types using the CUAD taxonomy
  • Risk Scoring: Evaluates clauses on a 0-1 risk scale with detailed explanations
  • Industry Benchmarking: Compares clause language to standard industry provisions
  • Interactive Interface: Upload contracts and explore results in real-time

Built with LangGraph, Claude AI, Streamlit, and CUAD Dataset
